
* **HTML5** — архітектура платформи, інтеграція адаптивної векторної графіки (вбудований HUD-приціл SVG).
* **CSS3** — темна Sci-Fi мілітарі-тема, анімація завантаження радара, адаптивна сітка Flexbox.
* **JavaScript (ES6)** — динамічний годинник, система перемикання мов (UKR/ENG) наживо, обробка тактичних запитів клієнта **Mykyta**.


 **Tactical HUD Splash Screen** — анімований екран завантаження з супутниковою сіткою та радаром.
 **Мультимовність** — миттєвий переклад інтерфейсу (Українська / Англійська) в один клік.
 **Каталог послуг та курсів** — інтерактивні картки із вікнами підтвердження запису.
 **Захищена форма зв'язку** — робоче вікно відправки контрактного запиту в командний центр ПВК.

1. Завантажте папку
2. Переконайтеся, що файли `index.html` та `style.css` (або стилі всередині) знаходяться разом.
3. Відкрийте файл `index.html` у будь-якому сучасному браузері.
